## 🔧 Customization

### Change Agent Model

Edit `model:` in frontmatter:

```yaml
---
description: Your agent
model: opus # or sonnet, haiku
---
```

### Create Custom Agent

1. Copy existing agent as template
2. Modify role, mission, checklist
3. Save to `.claude/agents/your-agent.md`
4. Use with `@your-agent`

## 🆘 Need Help?

### Agent not working?

1. Check model (Opus for complex, Sonnet for most)
2. Be more specific ("audit auth" → "audit auth.service.ts for A01-A03")
3. Provide context (stack, constraints, requirements)

### Conflicting advice?

- Use `@principal-architect` to make final call
- Consider trade-offs (security vs performance)

### Too much output?

- Ask for "top 5 issues only"
- Request "executive summary"
